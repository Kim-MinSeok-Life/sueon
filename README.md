# SUEO:N (수어온)

> **한국어를 말하거나 쓰면, 3D 아바타가 한국수어로 보여 줍니다.**
> 실제 농인이 촬영한 수어 데이터를 아바타 동작으로 옮겨, 청인과 농인 사이의 짧은 안내·대화를 돕는 모바일 웹앱입니다.

| 상태 | 단계 | 현재 범위 |
|---|---|---|
| ✅ **동작하는 프로토타입** | 핵심 기능 구현 완료 | 지하철역 길·안내 전달 상황의 문장 중심 |

| 입력 | 처리 | 출력 |
|---|---|---|
| 한국어 문장 · 음성 | 한국어 → 한국수어 단어 순서(글로스) 변환 | 3D VRM 아바타의 수어 동작 |

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🗣️ **음성·문장 입력** | 브라우저 음성 인식으로 말하거나 직접 입력. 모바일 화면 우선 |
| ✨ **AI 음성 교정** | 말이 끝나면 Google Gemini가 잘못 들린 말·띄어쓰기·어순을 문맥으로 바로잡아 입력칸에 다시 써 줌(예: `포를` → `표를`, `갈아타세요 9호선으로 급하시면` → `급하시면 9호선으로 갈아타세요`). 확인한 문장이 그대로 수어가 됨 |
| 🧠 **한국어 → 한국수어 변환** | 군말·더듬음·오타 정리, 조사·어미 제거, 용언 기본형 복원, 동음이의어 구분, 한국수어 어순(시간 앞·의문사 뒤·부정 동사 뒤) 적용 |
| 🧍 **실제 촬영 기반 아바타 동작** | AI-Hub 수어 영상의 3D 관절 좌표를 아바타 뼈대로 옮긴 **수어 단어 동작 1,351개**(문장 속 317 + 단어 영상 785 + 지문자·지숫자 249). 손바닥 방향·손가락 마디까지 재현하고 몸 관통을 막음 |
| 📖 **국립국어원 한국수어사전 연동** | 3,734개 항목으로 단어 뜻 분류와 손 모양 설명을 함께 표시 |
| 🙂 **의문문 표정** | 예/아니요 질문은 눈썹 올림, 의문사 질문은 눈썹 모음 표정을 함께 재생 |
| 🔊 **답하기** | 상대가 입력한 답을 음성(TTS)으로 읽어 줌 |
| 🔍 **검수 화면** | 원본 촬영 영상 · 아바타 · **국립국어원 한국수어사전 표준 영상**을 나란히 재생하며 단어별 일치 여부를 기록(개발용) |

**예시**

| 입력 | 이해한 수어 단어 순서 | 재생되는 동작 |
|---|---|---|
| `지금 3호선이 지연되고 있어요` | 지금 · 3호 · 지연되다 | 3개 모두 |
| `급하시면 9호선으로 갈아타세요` | 급하다 · 9호 · 갈아타다 | 3개 모두 |
| `종합운동장 방면으로 가셔야 해요` | 종합운동장 · 가다 (방향은 '가다'의 손 방향으로) | 2개 모두 |
| `어 그 그 택 택시 타고 가요` | 택시 · 타다 · 가다 (군말·더듬음 정리) | 3개 모두 |
| `택시 기본요금 얼마예요?` | 택시 · 기본 · 돈 · 얼마 (의문사 질문) | 4개 모두 + 의문문 표정 |

## 동작 원리

| 단계 | 하는 일 | 방식 |
|:---:|---|---|
| 1 | 음성 → 텍스트 | 브라우저 Web Speech API → Google Gemini가 오인식·띄어쓰기·어순 교정 |
| 2 | 문장 정리·형태 분석 | 직접 설계한 한국어 규칙 + 사전 조회 |
| 3 | 뜻 고르기 | 국립국어원 사전 분류 + 함께 쓰인 단어(문맥) |
| 4 | 한국수어 어순 | 시간·의문사·부정 위치 규칙 |
| 5 | LLM 판단 | Google Gemini가 단어 순서 후보를 제안하고, **규칙·사전이 다시 검증**(없는 단어 금지, 입력 근거 확인). 규칙만으로 확실한 문장은 LLM 없이 즉시 처리, API 키가 없거나 실패하면 2~4단계만으로 동작 |
| 6 | 동작 연결 | 단어마다 실제 촬영 동작을 찾고, 다른 뜻으로 촬영된 동작은 쓰지 않음 |
| 7 | 아바타 재생 | 단어 핵심 구간을 자연스럽게 이어 재생 |

**사람 동작 → 아바타 동작 (리타기팅)**

| 처리 | 내용 |
|---|---|
| 좌표 정규화 | 촬영자마다 다른 몸 크기·단위(mm/m)를 어깨 너비 기준으로 맞춤 |
| 팔·손 회전 | 방향과 비틀림(손바닥 방향)을 함께 계산, 손가락은 마디별 회전 |
| 손목 IK | 아바타 팔 길이가 달라도 손이 닿는 위치를 유지 |
| 관통 방지 | 아바타 몸 앞면을 측정해 팔·손이 몸을 뚫지 않게 보정 |
| 얼굴 근처 보정 | 귀·관자놀이·입 등 얼굴 접촉 위치를 머리 비율로 다시 맞춤 |

### 기술 구성의 구분

| 구성 | 분류 |
|---|---|
| 문장 분석·오타 교정·어순·동음이의어 | 직접 설계한 **규칙 + 사전 조회** |
| 아바타 동작 | 실제 촬영 데이터의 선택·자르기·**수학적 리타기팅** (동작을 새로 생성하지 않음) |
| 음성 인식 | 브라우저 제공 사전학습 모델 |
| LLM 판단 계층 | 외부 사전학습 모델(API) + 규칙 기반 검증 |

## 진행 상황과 로드맵

| 상태 | 항목 |
|---|---|
| ✅ 완료 | 한국어 → 한국수어 변환(규칙 + Gemini 검증), 음성 교정, 실제 촬영 기반 수어 동작 1,351개(실제 농인 3D 1,102 + 숫자·역 이름 지문자 249), 국립국어원 사전 연동, 리타기팅(손가락·관통 방지·얼굴 보정), 국립국어원 대조 검수 화면, 의문문 표정, 정확도·속도 측정 |
| 📋 계획 | 국립국어원 표준과 단어별 대조 검수 후 다른 동작 교체, 상황별 어휘 확장, 앞 문장까지 고려한 문맥 이해, 얼굴 키포인트 기반 비수지 표현, 카메라 기반 수어 인식(역방향), 시각장애인 지원, 다른 나라 수어로 확장 |

**측정 결과** (지하철역 안내 문장 20개 × 3회, 팀 기준 · [`reports/demo_accuracy_2026-11-05.json`](reports/demo_accuracy_2026-11-05.json))

| 항목 | 결과 |
|---|---|
| 뜻에 맞게 변환 | 60회 중 56회 (93%), 규칙만 쓰면 80% |
| LLM이 필요한 어려운 문장(붙여쓰기·오타·동음이의어·군말) | 15회 중 12회 (80%) |
| 처리 속도 | 규칙 약 0.2ms, LLM 중앙값 약 2.9초 |

> 수어 동작은 실제 촬영 데이터를 옮긴 것이지만, 국립국어원 표준과의 대조 검수와 한국수어 전문가 검수는 다음 단계에서 진행합니다.
