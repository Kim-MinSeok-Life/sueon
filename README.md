# SUEO:N (수어온)

> **한국어를 말하거나 쓰면, 3D 아바타가 한국수어로 보여 줍니다.**
> 실제 농인이 촬영한 수어 데이터를 아바타 동작으로 옮겨, 청인과 농인 사이의 짧은 안내·대화를 돕는 모바일 웹앱을 만들고 있습니다.

| 상태 | 단계 | 현재 범위 |
|---|---|---|
| 🚧 **개발 중** | MVP 구현 단계 | 교통·길 안내 상황의 문장 중심 |

| 입력 | 처리 | 출력 |
|---|---|---|
| 한국어 문장 · 음성 | 한국어 → 한국수어 단어 순서(글로스) 변환 | 3D VRM 아바타의 수어 동작 |

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🗣️ **음성·문장 입력** | 브라우저 음성 인식으로 말하거나 직접 입력. 모바일 화면 우선 |
| 🧠 **한국어 → 한국수어 변환** | 군말·더듬음·오타 정리, 조사·어미 제거, 용언 기본형 복원, 동음이의어 구분, 한국수어 어순(시간 앞·의문사 뒤·부정 동사 뒤) 적용 |
| 🧍 **실제 촬영 기반 아바타 동작** | AI-Hub 수어 영상의 3D 관절 좌표를 아바타 뼈대로 옮긴 **수어 단어 동작 1,102개**(문장 속 317 + 단어 영상 785). 손바닥 방향·손가락 마디까지 재현하고 몸 관통을 막음 |
| 📖 **국립국어원 한국수어사전 연동** | 3,734개 항목으로 단어 뜻 분류와 손 모양 설명을 함께 표시 |
| 🙂 **의문문 표정** | 예/아니요 질문은 눈썹 올림, 의문사 질문은 눈썹 모음 표정을 함께 재생 |
| 🔊 **답하기** | 상대가 입력한 답을 음성(TTS)으로 읽어 줌 |
| 🔍 **원본 대조 검수 화면** | 원본 촬영 영상과 아바타 동작을 나란히 재생하며 일치 여부를 기록(개발용) |

**예시**

| 입력 | 이해한 수어 단어 순서 | 재생되는 동작 |
|---|---|---|
| `택시 기본요금 얼마예요?` | 택시 · 기본 · 돈 · 얼마 (의문사 질문) | 4개 모두 + 의문문 표정 |
| `어 그 그 택 택시 타고 가요` | 택시 · 타다 · 가다 (군말·더듬음 정리) | 3개 모두 |
| `택시 탈 수 있어요?` | 택시 · 타다 · 가능 (예/아니요 질문) | 3개 모두 + 의문문 표정 |
| `배를 탔어요` | 배(교통 — 선박) · 타다 | 타다 — 보유한 '배' 동작은 신체 뜻이라 재생하지 않음 |

## 동작 원리

| 단계 | 하는 일 | 방식 |
|:---:|---|---|
| 1 | 음성 → 텍스트 | 브라우저 Web Speech API |
| 2 | 문장 정리·형태 분석 | 직접 설계한 한국어 규칙 + 사전 조회 |
| 3 | 뜻 고르기 | 국립국어원 사전 분류 + 함께 쓰인 단어(문맥) |
| 4 | 한국수어 어순 | 시간·의문사·부정 위치 규칙 |
| 5 | (선택) LLM 판단 | 외부 대형 언어모델이 단어 순서 후보를 제안하고, **규칙·사전이 다시 검증**(없는 단어 금지, 입력 근거 확인). API 키가 없으면 2~4단계만으로 동작 |
| 6 | 동작 연결 | 단어마다 실제 촬영 동작을 찾고, 다른 뜻으로 촬영된 동작은 쓰지 않음 |
| 7 | 아바타 재생 | 단어 핵심 구간을 자연스럽게 이어 재생 |

**사람 동작 → 아바타 동작 (리타기팅)**

| 처리 | 내용 |
|---|---|
| 좌표 정규화 | 촬영자마다 다른 몸 크기·단위(mm/m)를 어깨 너비 기준으로 맞춤 |
| 팔·손 회전 | 방향과 비틀림(손바닥 방향)을 함께 계산, 손가락은 마디별 회전 |
| 손목 IK | 아바타 팔 길이가 달라도 손이 닿는 위치를 유지 |
| 관통 방지 | 아바타 몸 앞면을 측정해 팔·손이 몸을 뚫지 않게 보정 |
| 얼굴 근처 보정 | 귀·관자놀이·입 등 얼굴 접촉 위치를 머리 비율로 다시 맞춤 |

### 기술 구성의 구분

| 구성 | 분류 |
|---|---|
| 문장 분석·오타 교정·어순·동음이의어 | 직접 설계한 **규칙 + 사전 조회** |
| 아바타 동작 | 실제 촬영 데이터의 선택·자르기·**수학적 리타기팅** (동작을 새로 생성하지 않음) |
| 음성 인식 | 브라우저 제공 사전학습 모델 |
| LLM 판단 계층 | 외부 사전학습 모델(API) + 규칙 기반 검증 |

## 기술 스택

| 영역 | 사용 |
|---|---|
| 웹앱 | Next.js 16 (App Router) · React 19 · TypeScript |
| 3D | Three.js · @pixiv/three-vrm (VRM 1.0 아바타) |
| 데이터 처리 | Python 3 + NumPy (키포인트 파싱, 리타기팅, 사전·동작 라이브러리 생성) |
| LLM (선택) | Anthropic SDK · OpenAI API |
| 테스트 | Node `node:test` · Python `unittest` |

| 수어 영상 3D 키포인트·형태소 | [AI-Hub 수어 영상](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=103) (이용약관 동의 후 사용) | 아바타 동작 생성, 원본 대조 |
| 한국수어사전 한국어대응표현정보 | 국립국어원 (공공데이터포털 15135637) | 단어 뜻 분류, 손 모양 설명 |
| 3D 아바타 | pixiv VRM 샘플 (VRM Public License 1.0) | 아바타 표시 |

> AI-Hub 원본 데이터(약 95GB)는 저장소에 포함하지 않습니다. 저장소의 수어 동작 파일(`public/motions/`)은 AI-Hub 데이터를 가공한 것으로, 다른 곳에서 쓰려면 AI-Hub 이용약관을 먼저 확인하세요. 자세한 출처와 조건은 [`CREDITS.md`](CREDITS.md)를 참고하세요.

## 실행 방법

| 단계 | Windows (PowerShell) | Mac (터미널) |
|:---:|---|---|
| 1 | `npm.cmd ci` | `npm ci` |
| 2 | `npm.cmd run dev` | `npm run dev` |
